Example-rot detection · one microVM per example · built on Solari

Do your examples still run?

Example code rots quietly — a transitive dependency breaks, a default changes, the README drifts — and nothing turns red, because examples are not tests. cookbook-canary runs them: each one alone, on its own hardware-isolated microVM, up to driving a real browser at the page and reading the rendered text back.

How it works

prepare · fan out · prove · report
01

Prepare once

One sandbox clones the repo, discovers the examples, infers how each is built and started, installs every example's dependencies, and snapshots the result.

02

Fan out

Each example gets its own microVM forked from that snapshot, up to concurrency at a time. A fork is a sub-second resume of an already-installed tree.

03

Prove it

Exit code, or a stdout regex, or — for anything that serves — poll the preview URL, then drive a real cloud browser at it and assert on the DOM. Failures keep a screenshot and a session replay.

04

Report

Markdown for a PR comment, JSON for a dashboard, standalone HTML for publishing. All three scrubbed of credentials.

03

Status, honestly

verified vs not yet verified

Verified

  • 125 tests / 25 suites — green in ~1.5s, no network
  • tsc --strict --noEmit — clean, zero any in src/
  • CI — green on every push, no SDK peers installed
  • --dry-run — exercised against this repo's own canary.json

Everything above the SDK adapter — discovery, prep, fan-out, retries, classification, budget, reporting — is proved end to end against a hand-built fake.

Not yet verified

  • The Solari adapter has never made a live call. No API key was available while it was written; every mapping is derived from the published typings, not the service.
  • The reports on this page are from a synthetic run, not a live run against the Solari API.
  • A live run is the top roadmap item — it needs credentials and is the only gap that cannot be closed without them.

The risk is concentrated by design: one file, ~390 lines, each mapping commented with the SDK surface it targets.
