Proves every example in a repo still runs — each one alone, on its own hardware-isolated microVM, built on Solari.

These are sample reports: real output from the report layer for a synthetic run, not a live run against the Solari API. Every credential-shaped string in them has been through the redactor.

  • HTML dashboard →Standalone, dark-mode aware, screenshots inlined as data URIs
  • Markdown report →What gets posted as a PR comment and written to the job summary
  • JSON artifact →Schema-versioned, for dashboards built on top of a run
  • Source on GitHub →How a run works, why one microVM each, and what is not yet verified
